# Прототип сайта индекса качества городской среды

Рабочая папка `site` содержит фронтенд, подготовленные данные и скрипты сборки. Исходные GIS-слои из `Diser` не публикуются напрямую: тяжелые исходники лежат в `site/data/_raw` и исключены из Git.

## Что собрано

- стартовое меню городов с рейтингом;
- 3D-карта Орла и Тамбова без подложки;
- квартальные слои с индексами, рангом и сценарным пересчетом;
- здания, зеленые зоны, УДС, остановки и ДТП;
- разделение автобусных и трамвайных остановок;
- попап ДТП с датой, пострадавшими и погибшими;
- подсказки по субиндексам и показателям;
- мобильная нижняя панель с раскрытием свайпом.

## Команды

```powershell
node site\scripts\build-data.mjs
node site\scripts\build-3d-data.mjs
node site\scripts\build-dist.mjs
node site\scripts\serve.mjs
node site\scripts\serve.mjs site_dist
```

## Публикация

Для Cloudflare Pages используется папка `site_dist`. Она собирается командой:

```powershell
node site\scripts\build-dist.mjs
```

В `site_dist` попадают `index.html`, `2d.html`, `3d.html`, `src`, `public`, подготовленные GeoJSON из `site/data` и тайловые 3D-данные из `site/data3d`. Папка `site/data/_raw` не копируется и не должна публиковаться.

## Cloudflare Pages

Настройки Git-сборки:

```text
Framework preset: None
Build command: node site/scripts/build-dist.mjs
Build output directory: site_dist
Production branch: main
NODE_VERSION: 22
```

## Методика в интерфейсе

Базовый городской рейтинг берется из подготовленных данных проекта. Базовый квартальный индекс берется из нормализованных квартальных показателей. Сценарный индекс в интерфейсе считается в браузере как среднее активных субиндексов квартала и не заменяет базовую методику.
